## Box Select and Freehand Blur: Two Precise Ways to Hide Image Details

When you need to blur part of an image, the shape of the hidden area matters. A brush is useful for quick touch-ups, but some privacy edits need cleaner control. That is where **box select blur** and **freehand selection blur** help.

Use box select when the private detail is rectangular, such as a screenshot panel, license plate, form field, receipt line, address label, or screen. Use freehand selection when the area has an irregular shape, such as a face outline, badge, object, hand, reflection, or background detail that does not fit neatly inside a rectangle.

This guide explains when to use each method, how to get a clean result, and how to avoid common mistakes before sharing an image online.

## Quick Answer

Use **box select blur** for straight-edged areas and **freehand blur** for irregular areas. In Toolbox Image, open the paint tool, choose the selection mode, draw over the area you want to hide, adjust the blur effect, and download the edited copy.

## What Is Box Select Blur?

Box select blur lets you drag a rectangle over the part of an image you want to hide. When you release the selection, the selected area receives the chosen blur effect.

It is the fastest precise method when the private detail already has a rectangular shape. You do not need to paint back and forth with a brush, and the final edge is predictable.

Good use cases include:

- Names, emails, and order IDs in screenshots

- Address blocks on shipping labels

- License plates in car photos

- Spreadsheet cells and dashboard widgets

- Chat messages and browser tabs

- Receipts, forms, and account numbers

- Computer screens in the background

Box select is also easier to repeat across multiple similar images because the shape is simple and visually consistent.

## What Is Freehand Selection Blur?

Freehand selection blur lets you draw around an area with a custom outline. Instead of covering a rectangle, the blur is applied inside the hand-drawn shape.

This is useful when a rectangle would hide too much. For example, a rectangular blur around a face may also cover clothing, background, or another person. A freehand selection can follow the rough shape of the private area while keeping more of the image clear.

Freehand selection works well for:

- Faces in group photos

- ID badges and name tags

- Reflections in windows or mirrors

- Hands holding private documents

- Objects on a desk

- Personal details near important visual context

- Background people or signs

The goal is not to draw a perfect outline. The goal is to hide the sensitive detail while preserving useful context around it.

## Box Select vs Freehand Blur

| Editing need | Best option | Why it works |
| --- | --- | --- |
| Hide a screenshot text block | Box select | Text areas usually align to straight rows |
| Blur a license plate | Box select | Plates are rectangular and need strong coverage |
| Hide one face in a crowd | Freehand selection | The shape is not a clean rectangle |
| Cover a screen on a laptop | Box select | Screens have straight edges |
| Blur a badge on clothing | Freehand selection | The badge may sit at an angle |
| Remove a distracting object | Freehand selection | Objects often have uneven outlines |

If you are unsure, start with box select for speed. If it hides too much, undo and use freehand selection instead.

## How to Use Box Select Blur

- Open **[Blur Part of Image Online](/blur-image)**.

- Upload your photo, screenshot, or web image.

- Switch to the paint blur tool.

- Choose the box select mode.

- Drag from one corner of the private area to the opposite corner.

- Release to apply the selected blur effect.

- Check the result at normal size and zoomed in.

- Download the blurred image.

For privacy edits, include a little padding around the detail. Do not select only the exact letters, digits, or face edge. A slightly larger blur area is safer after compression, resizing, or reposting.

## How to Use Freehand Selection Blur

- Open the image in the paint blur tool.

- Choose the freehand selection mode.

- Draw around the area you want to hide.

- Keep the line slightly outside the private detail.

- Release to apply blur inside the selected outline.

- Use undo if the shape is too tight or too wide.

- Download the final image after checking the whole frame.

Use slower hand movement around small private details. On mobile, zoom your browser if needed, then draw the outline with a little extra space.

## Choose the Right Blur Effect

The selection shape controls where the edit happens. The blur effect controls how hidden the detail becomes.

For private information, use stronger blur or pixelation. Faces, numbers, addresses, account names, IDs, QR codes, and license plates should not be recognizable after zooming.

For visual cleanup, use a softer blur. Background clutter, logos, messy shelves, or distracting objects often need only a mild blur so the image still feels natural.

Common choices:

- **Gaussian blur** for a smooth privacy cover

- **Pixel blur** when you want the edit to be obvious

- **Motion blur** for stylistic or background edits

- **Strong blur** for text, plates, and sensitive details

## Common Mistakes to Avoid

The biggest mistake is making the selection too tight. If a name, number, or face touches the edge of the blur area, it may still be partially readable after resizing or sharpening.

Another mistake is using a rounded preview for a rectangular result. The preview shape should match the final blur shape, so you can judge exactly what will be hidden.

Also check the rest of the image before downloading. A screenshot may contain private details in the browser bar, sidebar, tabs, notifications, or background windows. A photo may include reflections, badges, documents, or location clues.

## A Simple Privacy Checklist

Before sharing an edited image, review these areas:

- Faces and names

- Email addresses and phone numbers

- Home or office addresses

- License plates

- Order numbers and account IDs

- Browser tabs and URLs

- Chat names and avatars

- Screens, mirrors, and reflections

- QR codes and barcodes

- Documents in the background

If the image contains legal, financial, medical, or identity information, use a stronger effect and add more padding.

## Frequently Asked Questions

### Is box select blur better than brush blur?

Box select blur is better for rectangular areas because it is faster and cleaner. Brush blur is better for small touch-ups or areas that need soft manual control.

### When should I use freehand selection blur?

Use freehand selection blur when the area is irregular and a rectangle would hide too much. Faces, badges, reflections, background people, and objects often work better with freehand selection.

### Can I use different blur effects with box select and freehand selection?

Yes. The selection mode defines the area, while the blur effect defines the visual style. You can use smooth blur, pixel blur, motion blur, or stronger blur depending on the privacy risk.

### Should I blur more than the exact private detail?

Yes. Add padding around faces, text, numbers, and plates. Padding reduces the chance that a detail remains readable after the image is compressed, resized, or viewed on another screen.

## Conclusion

Box select blur and freehand selection blur solve different privacy problems. Use box select for clean rectangular areas like screenshots, plates, labels, and forms. Use freehand selection for faces, badges, objects, and irregular details.

For the best result, choose the shape first, then choose the blur effect. Keep the selection slightly larger than the sensitive detail, review the full image, and download a clean copy before sharing.
